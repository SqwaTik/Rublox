# Rublox

**AI-ассистент для разработки игр в Roblox Studio.**

Чат с любой LLM (Claude · ChatGPT · Gemini · локальные модели), мост к плагину Studio
и **67 инструментов**, которыми ИИ строит, скриптует и отлаживает прямо в твоём плейсе.

</div>

---

## Что умеет Rublox

- **Работает внутри Studio.** ИИ выполняет Lua прямо в открытом DataModel: создаёт объекты, пишет постоянные скрипты, читает консоль, чинит ошибки и проверяет результат.
- **Строит по генплану.** Сначала проектирует план постройки (вид сверху, видно в чате), затем возводит её из частей одним вызовом — красиво и осмысленно.
- **67 инструментов.** Объекты, свойства, иерархия, теги, атрибуты, скрипты, UI, физика-констрейнты, свет, звук, частицы, освещение сцены, поиск ассетов в Toolbox, веб-поиск и работа с файлами ПК.
- **ИИ-плагины (скиллы).** Включаемые модули поведения: Архитектор, Скриптинг, UI-дизайнер, Отладчик, Оптимизатор, Canvas, Веб-исследователь. Можно добавлять свои.
- **Знает Luau.** Перед написанием кода сверяется со встроенным справочником (29 тем) и ищет в интернете, если не уверен — с отображением источников, как у крупных ИИ.
- **Помнит весь чат.** История на диске, авто-резюме при росте контекста, аккуратное переключение между чатами без «утечки» ответа в чужой чат.
- **Красивый клиент.** 9 тем со свотчами-превью, glassmorphism, markdown с подсветкой и diff (зелёное «+», красное «−»), векторные SVG-иконки, анимация «печатает», todo-план как в Claude.
- **Любой провайдер.** Anthropic / OpenAI / Gemini / OpenRouter / Groq / локальные — мини-пикер моделей: указал ключ, подтянулись рабочие модели.
- **Десктоп-приложение** (Electron) со сворачиванием в трей и установкой плагина одной кнопкой.

## Архитектура

```
  Веб-чат (web/)  ──WebSocket──►  Сервер-мост (server/)  ──HTTP API──►  LLM
        ▲                              ▲
        │                              │ long-poll
        └── статус Studio              ▼
                              Плагин Studio (plugin/)
```

Плагин не принимает входящих соединений — он сам опрашивает сервер
(`/api/roblox/poll`), выполняет команды и присылает результат
(`/api/roblox/result`). Это совместимо с песочницей Studio и не требует открытых портов.

## Установка и запуск

```bash
cd roblox-ai-assistant
npm install
cp .env.example .env      # на Windows: copy .env.example .env
npm start
```

Откройте <http://localhost:8787> — это веб-чат. Ключи провайдеров можно ввести
прямо в UI (вкладка **Providers**) или в `.env`:

- `ANTHROPIC_API_KEY` — для Claude;
- `OPENAI_API_KEY` — для ChatGPT;
- `LOCAL_BASE_URL` — для локальной модели (Ollama / LM Studio / vLLM).

Bridge-токен для плагина генерируется автоматически и виден на вкладке **Connection**.

## Десктоп-приложение (трей)

```bash
npm run desktop        # запуск в режиме разработки
npm run build          # установщик NSIS → dist/
```

Приложение запускает сервер внутри себя, живёт в трее (крестик прячет окно, не
закрывает). Данные упакованной версии — в `%APPDATA%\Rublox`.

> Подсказка для Windows: если `electron-builder` падает на распаковке `winCodeSign`
> (симлинки `libcrypto.dylib`/`libssl.dylib`) — это нужно только для подписи под
> macOS. Включите Developer Mode; на сборку под Windows эти файлы не влияют.

## Подключение плагина Studio

1. В сайдбаре нажмите **«Установить плагин»** (или клик по статусу «Studio: отключён»).
   Сервер соберёт `Rublox.rbxm` и положит его в папку плагинов Roblox.
2. В **Game Settings → Security** включите **Allow HTTP Requests**.
3. Перезапустите Studio, откройте панель **Rublox**, нажмите **Connect**
   (URL и токен подставляются автоматически).
4. Индикатор в веб-чате сменится на «Studio: подключён».

## Как это работает

ИИ выполняет Lua **прямо в открытом DataModel**. Когда ты пишешь «сделай спринт на
Left Shift», ассистент создаёт **постоянный** `LocalScript` в
`StarterPlayer.StarterPlayerScripts` — он остаётся в плейсе и работает при запуске
Play, без внешних файлов. Серверная логика идёт в `ServerScriptService`, общие
модули — в `ReplicatedStorage`. Это не Rojo: файлы на диске не генерируются.

## ИИ-плагины (скиллы)

Вкладка **Plugins** в настройках. Каждый включённый навык добавляет инструкцию в
системный промпт и реально меняет поведение ИИ:

| Навык | Что делает |
|---|---|
| Архитектор построек | генплан → аккуратная постройка из частей |
| Мастер скриптинга | сверяется с докой, пишет идиоматичный Luau |
| UI-дизайнер | строит интерфейсы (ScreenGui, раскладки, скругления) |
| Отладчик | читает консоль, чинит ошибки сам |
| Оптимизатор | следит за производительностью |
| Canvas | цельные документы + точечные diff-правки |
| Веб-исследователь | при сомнении ищет в интернете |

Кнопка **«Добавить свой навык»** — задаёшь имя и инструкцию, и ИИ начинает ей следовать.

## Документация по Luau (для ИИ)

`docs/luau-roblox.md` — справочник на 29 тем (основы, сервисы, события, физика и
CFrame, RemoteEvent, GUI, TweenService, Raycasting, RunService, CollectionService,
атрибуты, ModuleScript, ООП, анимации, констрейнты, Pathfinding, типы данных и др.).
ИИ обращается к нему через `luau_reference(topic)` перед написанием кода.

## Слеш-команды

| Команда | Назначение |
|---|---|
| `/help` | список команд |
| `/connect`, `/disconnect`, `/status` | подключение к Studio и состояние |
| `/models`, `/model <id>`, `/setmodel <имя>` | провайдеры и модели |
| `/persona <текст>`, `/context <текст>` | роль и контекст |
| `/compact`, `/reset` | свернуть / очистить историю |
| `/run <lua>`, `/insert <assetId>`, `/console`, `/tree` | прямые действия в Studio |
| `/play`, `/stop`, `/playrun <lua>` | Play-режим |
| `/templates`, `/template <id> [json]` | готовые шаблоны кода |
| `/local <команда>` | команда на ПК (при отключённом Studio) |

## Провайдеры и кастомные модели

Любой OpenAI- или Anthropic-совместимый сервис добавляется прямо в UI или через
`providers.json`. `kind` задаёт протокол (`openai` подходит для OpenRouter, Groq,
Together, Mistral, DeepSeek, vLLM, Ollama, LM Studio). Ответ стримится
токен-за-токеном (SSE) для обоих протоколов; tool-calls собираются из стрима
инкрементально.

## Структура проекта

```
server/
  index.js        — HTTP + WebSocket + REST для плагина и API
  agent.js        — агентный цикл с tool-use + самопроверка инструментов
  session.js      — сессии, история, компрессия, системный промпт
  skills.js       — ИИ-плагины (скиллы) и их влияние на промпт
  bridge.js       — очередь команд и long-poll к плагину
  store.js        — сохранение сессий на диск
  luau-reference.js — доступ к docs/luau-roblox.md
  llm/
    providers.js  — Anthropic / OpenAI / local + стриминг
    registry.js   — реестр провайдеров
    tools.js      — схемы всех инструментов + наборы по режимам
web/              — веб-чат (HTML/CSS/JS), темы, иконки, i18n
plugin/           — плагин Roblox Studio (RubloxPlugin.server.lua)
docs/             — справочник по Luau/Roblox
data/             — сохранённые сессии (создаётся автоматически)
```

## Безопасность

- Команды в Studio выполняются только по запросу из чата и логируются в плагине.
- Запросы к серверу-мосту авторизуются bridge-токеном.
- ПК-агент (`/local`) работает только при отключённом Studio и управляется тумблером.
