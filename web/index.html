TRELLIS бесплатно Открыть Space ↗
TRELLIS — бесплатная нейросеть Microsoft для генерации 3D из текста, размещённая на Hugging Face. Что делать: 1) открой Space по ссылке выше → нажми три точки → Duplicate this Space (свой стабильный экземпляр) ИЛИ используй публичный; 2) скопируй его URL (вида https://ИМЯ.hf.space) сюда; 3) выбери провайдер TRELLIS вверху и сохрани. Важно: публичные Space бывают перегружены (очередь/таймаут) — для надёжности дублируй Space к себе. HF-токен нужен только для приватных Space.
